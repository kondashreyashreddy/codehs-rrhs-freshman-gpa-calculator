# Round Rock High School Freshman Year (9th Grade) Grade Point Average Calculator
## Program
This program uses almost all official registered courses for the RRHS 2026-2027 SY Freshman choice sheet and Round Rock ISD's official public GPA algorithm to calculate End-Of-Year GPA for Freshman students at Round Rock High School.
